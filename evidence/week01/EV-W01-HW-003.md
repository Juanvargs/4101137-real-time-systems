## Reproduction

```bash
source ~/zephyrproject/.venv/bin/activate
cd ~/zephyrproject/zephyr

west flash \
  -d build/blinky-nucleo-g474re \
  --runner pyocd
```

## Programming result

- Runner: pyOCD 0.45.1 through the on-board STLINK-V3.
- Image: `build/blinky-nucleo-g474re/zephyr/zephyr.hex`.
- Flash base address: `0x08000000`.
- Erased: 20,480 B in 10 sectors.
- Programmed: 19,456 B in 19 pages.
- Reported throughput: 21.51 kB/s.
- No runner error was reported.

## Physical observation

The student confirmed that the green user LED `LD2` alternated between on and off
approximately once per second after programming. For this board, Zephyr maps the
`led0` devicetree alias to `LD2` on pin `PA5`.

## Interpretation and limitation

This result verifies the Zephyr board definition, ARM firmware generation, USB
permissions, pyOCD target support, STLINK-V3 programming path, MCU startup, and
basic GPIO output. It does not verify the serial console or any real-time property
of SoilSense; no latency, jitter, or deadline measurement was performed.
